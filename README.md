# Software Engineer Quiz Bank 🧠⚡

An open-source collection of categorized software engineering quiz questions and explanations across frontend, backend, devops, database, and system architecture.

Used by [Agung Sundoro's Portfolio](https://agungsundoro.com).

## 📁 Repository Structure

```text
├── questions/
│   ├── bash.json
│   ├── css.json
│   ├── docker.json
│   ├── git.json
│   ├── javascript.json
│   ├── php.json
│   ├── python.json
│   ├── react.json
│   ├── typescript.json
│   ├── vue.json
│   └── ...
├── index.json          # Auto-generated by GitHub Action
└── .github/workflows/
    └── index.yml       # Auto-indexes questions on commit
```

## 🌐 Consuming via GitHub Raw

### 1. Index
```http
GET https://raw.githubusercontent.com/agung2001/software-engineering-quiz/main/index.json
```

### 2. Specific Tool Questions
```http
GET https://raw.githubusercontent.com/agung2001/software-engineering-quiz/main/questions/{tool}.json
```
Example:
```http
GET https://raw.githubusercontent.com/agung2001/software-engineering-quiz/main/questions/vue.json
```

## 📝 Question Schema

Each file in `questions/<tool>.json` contains an array of question objects:

```json
[
  {
    "question": "What does CSS property 'contain: layout' do?",
    "code": "/* optional code block */",
    "options": [
      "Isolates the element from the rest of the page layout",
      "Hides overflow content",
      "Prevents mouse events",
      "Clears floats automatically"
    ],
    "correct": 0,
    "difficulty": "Intermediate",
    "explanation": "contain: layout isolates the element internal layout so changes do not trigger layout recalculations outside."
  }
]
```
